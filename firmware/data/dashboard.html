Auto-calibrate: leave the device untouched for 10 s, then make blops for 20 s (tap the vessel or let the airlock work). Trigger and release are set between the noise peaks and the weakest blops and saved.

A blop is a sharp rise of the gyro signal above the trigger. Set the trigger clearly above the noise floor and below typical bubble peaks. The release level only ends an event for the diagnostics; the spacing is the shortest interval between two counted blops.
